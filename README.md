# Lobo Mau de Marina

A tiny browser game for a two-year-old, starring the Big Bad Wolf.

- **Dressing room:** tap a piece of clothing and the wolf puts it on. Tap again to take it off.
- **Eggs:** tap the egg button. The wolf eats it and grows bigger and stronger.
- **The three houses:** tap the green house button, then the blue wind button to blow. Straw and sticks fly away; the brick house only falls once the wolf has eaten 3 eggs (or after a few tries, so nobody gets stuck).
- **Again:** the orange arrow rebuilds the houses. The purple hanger goes back to the clothes.

No text to read, big buttons, sounds and Portuguese voice (uses the device's speech voice when available). The small speaker in the corner mutes everything.

## Run it

It's a single file with no dependencies. Open `index.html` in any browser, or turn on GitHub Pages (Settings → Pages → deploy from `main`) and open it on a tablet. Landscape works best.
